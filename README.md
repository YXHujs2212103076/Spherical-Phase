# Spherical-Phase Metalens: Aberration-Free Focusing Independent of Medium Interface

**Published in *Optics Communications*, Volume 617, 133389 (2026)**  
📄 DOI: [10.1016/j.optcom.2026.133389](https://doi.org/10.1016/j.optcom.2026.133389)

This repository contains the MATLAB code for spherical aberration characterization via equiphase ray tracing, as described in the above paper. The code reproduces **Fig. 7** of the paper (normal-vector ray tracing diagrams and spherical aberration curves) for both hyperbolic and spherical phase profiles.

## Quick verification
Run the main script to generate the results shown in Fig. 7.  
Typical execution time: < 10 seconds.
